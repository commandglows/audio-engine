# Windows MF decoder trials

Standalone native test for `flutter/shipglows_audio/windows/windows_mf_decoder.*`.
No Flutter, no engine, no device output.

## Files

- `fixture_specs.h`: fixture table shared by the generator and the runner (expectations, tones, tolerances).
- `fixture_gen.cpp`: writes the fixtures and `generated.tsv` (status and HRESULT per fixture).
- `decoder_trials.cpp`: opens each fixture through `WindowsMfDecoder`, checks it, prints the matrix.
- `CMakeLists.txt`: standalone CMake project, CTest registration.

## Provenance and licence

- Content is original synthetic sine tones generated by `fixture_gen.cpp` (440 Hz mono; 997 Hz left / 1499 Hz right stereo; 2.0 s; amplitude 0.5; 10 ms fades). No recordings, samples or third-party audio are used or downloaded.
- Licence: same as the repository (`LICENSE`, proprietary, CommandGlows). Nothing here is third-party material.
- Encoding: WAV is written directly as RIFF/WAVE. AAC-LC and ALAC are encoded by Microsoft's Media Foundation encoder MFTs through `IMFSinkWriter` into MP4 (`.m4a`). MP3 is encoded by the Media Foundation MP3 encoder MFT driven directly; its raw MPEG-1 Layer III frames are written as `.mp3` (no ID3 tags).
- Not generated: FLAC. Media Foundation has no FLAC file sink. The FLAC case only tests the extension gate (`not_flac_bytes.flac` is WAV bytes, not a FLAC stream).
- Damaged and mislabelled inputs are derived from the generated files (header overwritten, truncated, renamed).
- Generated binaries are git-ignored and must never be committed.

## Build and run

```powershell
cmake -S tests/decoder_trials -B build/decoder-trials -G "Visual Studio 17 2022" -A x64
cmake --build build/decoder-trials --config Release
ctest --test-dir build/decoder-trials -C Release --output-on-failure
```

Direct run (after building):

```powershell
build\decoder-trials\Release\shipglows_fixture_gen.exe build\decoder-trials\fixtures
build\decoder-trials\Release\shipglows_decoder_trials.exe build\decoder-trials\fixtures
```

The runner exits non-zero on any mismatch. Fixtures reported as `NOT GENERATED` (with the HRESULT in `generated.tsv`) are shown but do not fail the run.
