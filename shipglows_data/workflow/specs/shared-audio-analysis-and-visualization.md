# Title

Shared optional audio analysis and original visualization

## Status

**Draft 1.2.0, not ready.** Operator approval ('validé') covers source-neutral streaming/chunked analysis, bounded recent-feature batches, optional spectrum/two profiles, one shared sequential visual transform and independent Stage A/Stage B. Do not ask again for these decisions. Approved direction is not implementation authority in this document-editing run, runtime proof or public schema freeze.

Stage A: shared analysis/transform/bridge/streaming offline, bars and readable waveform/envelope, fixture video render. Stage B: radial/immersive, deterministic particles, presets and calibrated quality tiers. All four inspirations remain; Stage A acceptance cannot require Stage B. Current ContentGlows production adapter stays180s/30fps pending separate approval/deferred final-mix proof. Engine structure supports longer streams/hour-long fixtures without approving production costs/platforms/sources.

English internal documentation convention; parent GPT-6.1-Sol coordinated investigations, delegate identity unasserted. Product placement/default activation/persistence/token bindings/design and actual rollout remain gates. Exact defaults below are bounded draft contracts; measurement spike before freezing public schemas. Only this spec changes; no implementation/commit/tracker/other-engine edits.

## User Story

Listeners/creators enable original scenes backed by common physical measurements and common deterministic visual transform. Stage A offers bars/music oscilloscope/readable speech envelope; Stage B immersion/particles. Sequential identical PCM/config/continuity gives equivalent transformed records within tolerance. Same supplied transformed records/bracket/prepared-window context/effective config/brand/viewport/seed/time gives matching scene state. Delivery loss/different PCM gaps may change live display; no scientific realtime/pixel/MP4 identity claim.

## Minimal Behavior Contract

Source adapter supplies PCM identity/format/sample position/discontinuity to bounded streaming analyser. Requested physical features feed one native visual transform off callback; recent batches reach supported scenes. Offline streams validated WAV with explicit budgets; random-access render reads precomputed transform, never replays smoothing. Unsupported/invalid/gapped input honest state,not fake energy. Same-generation playback seek adapter fence resets core continuity/history; product generation not a core field.

## Success Behavior

Audio/source/gain/effects unchanged. No FFT unless spectrum requested. Speech readable rolling envelope distinct from42.7ms oscilloscope. Native live/offline share measurement/transform; renderers no recurrent filters. Batches normally retain10ms records; bounded resync not endless catch-up. Stage A fixtures/core independent of Stage B/production exporter. Atomic validated results/stateless arbitrary-order render. Accessible off/reduced/static and explicit quality/timing/capabilities; numerical/build/device/integration proof separate.

## Error Behavior

States disabled/warming_up/live/paused/ended/gap/unavailable/failed. Known zero PCM silence; missing PCM core discontinuity resets analyser/transform. History overwrite/slow bridge DELIVERY loss,not PCM reset; resync carries already-transformed recent window. Stale lease/stream/adapter-generation rejected. Release failure uncertainty. Invalid PCM offline fails/live gaps,never blocks output. Absent requested feature unavailable,not zero. Budget/cancel/parser/auth/mux mismatch fail closed,no partial success. Unsupported Stage B renderer cannot remove Stage A/silently mutate count.

## Problem

No shared timed features API. Independent DSP/renderer smoothing diverges; source-specific core clocks/three-minute sidecar prevent reusable podcasts. Single latest records lose transients. Measurement,aesthetic transform,draw need separation without copied templates/second player/mixer.

### Shared sequential visual transform sgav-visual-transform-1

Independent of brand/palette/audio effects. Exact config {version:1,sensitivity_db,amplitude_gamma,attack_ms,release_ms,spectrum_floor_db,spectrum_ceiling_db}; finite ranges [-24,24],[0.25,2],[1,200],[10,2000],[-120,-20],[-6,12],floor<ceiling. Selected calibration defaults0dB,gamma0.8,attack20ms,release180ms,floor-80dB,ceiling0dB. Fixed range,NO adaptive normalization/onset/beat. Canonical RFC8785 effective config/hash (including explicit defaults),transform version/profile/mask in cache.

Amplitude map u(a)=clamp(a*10^(sensitivity_db/20),0,1)^gamma. For each of six nonnegative level channels and64 requested display bands: y_initial=0; for record j with real m frames, dt=m/48000 seconds, tau=attack_ms/1000 if u>previous_y else release_ms/1000; alpha=1-exp(-dt/tau); y=previous_y+alpha*(u-previous_y). Consume canonical float32 physical values promoted to float64,same input live/offline;float64 unrounded internal recurrence state,float32 emitted. Initial first record blends from0,not instantaneous first-value init. Transform is causal in sequential MEASURED records; centered measurement lookahead still contributes to latency. No Dart/TS recurrent copy.

Frequency mapping from requested physical P[k]: edges e_b=20*1000^(b/64),b0..64. Cells C_k=[max(0,(k-.5)*F/N),min(F/2,(k+.5)*F/N)],k1..1024;Q_b=sum(overlap(C_k,band)/length(C_k)*P[k]),DC excluded. Correlated low bands/total allocation<=included power,no independent resolution claim. Band target u_b=0 if Q_b=0,else clamp((10*log10(2*Q_b)+sensitivity_db-floor)/(ceiling-floor),0,1)^gamma,then same attack/release.64 normalized visual values,NOT physical calibrated energy.

Music visual oscilloscope256 values sign(x)*u(abs(x)) for min/max,pointwise (no phase-smearing per-bin EMA). Speech stores each hop's already smoothed six visual levels exactly once. A pure source feature sampler projects RMS index5/peak index2 into the readable view; no repeated300-float physical/visual arrays, no new EMA or DSP in Dart/TS. Physical measurement fields retained separately; aesthetics never relabel normalized values dBFS/SPL.

PCM discontinuity/new stream resets y0,clear partial FFT/oscilloscope,increment continuity; delivery overwrite does NOT reset transform. Clean EOF processes final m/centered pads once,does not append synthetic release decay. Offline serial pass stores transformed records; random-order render never replays filter or depends on predecessor frame. Identical PCM/config/continuity/chunk partitions same numerical records; live PCM gaps explicit reset,not promise of gap-free offline equality.
